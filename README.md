
# বাজার দর | BazarDor

A responsive Bangla market-price website that helps users explore daily prices of essential products and compare prices across different markets.

## Technologies Used

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- DaisyUI
- Better Auth
- REST API

## Key Features

- Responsive design for mobile, tablet, and desktop.
- Browse products with daily prices and price changes.
- Explore products by category.
- Sort products by price from low to high or high to low.
- View product details and market-wise prices.
- Sign up and sign in with email/password or Google.
- View and update user profile information.
- Skeleton loading states and toast notifications.
- Custom 404 page for invalid routes.
